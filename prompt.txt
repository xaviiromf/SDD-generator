1. ARCHITECTURAL & TECHNICAL DIRECTIVES (EXTREME PERFORMANCE + TOP-TIER UX/UI)
--------------------------------------------------------------------------------
To guarantee an Awwwards-caliber visual experience with zero UI lag (smooth 60 FPS under heavy interaction, zero freezes when opening complex menus or typing):

- Core Framework: React 19 / 18 with TypeScript in strict mode.
- Bundler / Tooling: Vite with optimized tree-shaking and instant HMR.
- State Management & Re-render Isolation (NON-NEGOTIABLE):
  * FORBIDDEN: Do NOT use React Context for the core editing state; doing so causes cascading re-renders across the entire DOM tree whenever an accordion opens or a character is typed.

- Off-Main-Thread Compilation:
  * The rule-based engine, template interpolation, and markdown generators must execute in debounced microtasks (requestAnimationFrame / 16ms cadence) or via a lightweight Web Worker so live typing never competes with the main UI thread.
- Styling, UI & Motion:
  * Tailwind CSS configured with dynamic CSS Custom Properties (Design Tokens).
  * Strict Iconography Engine: Exclusively use `lucide-react` for all UI icons (navigation, status, controls, file tree). Emojis are strictly banned everywhere.
  * Headless primitives (Radix UI / Headless UI patterns) for full keyboard navigation (WAI-ARIA compliance).
  * Fast memoized syntax highlighting with Shiki or a lightweight PrismJS engine.
- Zero-Backend In-Memory Packaging:
  * JSZip + FileSaver to bundle the entire multi-folder project hierarchy (`specs/`, `prompts/`, `docs/`, `constitution.md`) into a `.zip` archive in under 100ms completely within browser memory.
